# Приложение № 2 к договору ДОГ-КА-2026-118

АО «Кедровые лаборатории», далее Заказчик, и ООО «Медный Ток», далее Исполнитель,
согласовали порядок сопровождения проекта Кедровый Атлас после приёмки оборудования.
Приложение действует с 1 декабря 2026 года по 28 февраля 2027 года.

## 1. Предмет и границы сопровождения

Исполнитель поддерживает конфигурацию сети и сбор событий, выполняет диагностику,
помогает восстанавливать отчёты и контролирует результаты резервного копирования.
Эксплуатация офисных рабочих станций, учётная система бухгалтерии и публичный сайт
не входят в предмет настоящего приложения. Увеличение числа рабочих мест требует
отдельного согласования и не изменяет автоматически количество оплачиваемых часов.

Ответственный сервис Заказчика — atlas-monitor. Основной узел находится по имени
monitor01.atlas.test и адресу 10.82.14.31. Резервный узел — monitor02.atlas.test,
адрес 10.82.14.32. Сборщик пишет файлы в /srv/atlas/monitoring/reports. Эти имена,
адреса и структура каталогов используются только внутри команды эксплуатации.

## 2. Стоимость и расчёты

| Условие | Стоимость |
|---|---:|
| Ежемесячное сопровождение, до 12 часов | 84 000,00 ₽ |
| Дополнительный час в рабочее время | 4 200,00 ₽ |
| Дополнительный час в согласованное ночное окно | 6 300,00 ₽ |
| Выезд по отдельной заявке | 18 600,00 ₽ |
| Лимит расходов за весь период без допсоглашения | 252 000,00 ₽ |

Цены приведены с НДС. Три месяца базового сопровождения составляют 252 000,00 ₽.
Двенадцать часов являются включённым объёмом за один месяц, а не числом смен.
Неиспользованный включённый объём на следующий месяц не переносится. Дополнительный
час учитывается только после согласования ответственного представителя Заказчика.
Все ставки, лимиты и график взаиморасчётов являются закрытыми коммерческими условиями.

## 3. Доступ и передача ответственности

Заявки принимает service-desk@cedar-lab.example. Представитель Заказчика —
Лидия Сергеевна Вересова; представитель Исполнителя — Павел Олегович Туманов.
Изменение контактного лица направляется с согласованного корпоративного адреса.
Финансовые документы принимаются через закрытый реестр FIN-ATLAS-2026-Q4.
Внутренний код Заказчика в реестре — CL-ATLAS-204, код поставщика — VN-COPPER-118.
Эти коды являются идентификаторами карточек и не являются паролями.

Доступ в систему выдаётся по персональной заявке и ограничивается сроком работ.
Постоянный пароль или общий токен в текст договора не включается. Строка
«пароль выдаётся отдельно» не содержит значения секрета и не подлежит замене целиком.
Для подписания актов используется общая папка /srv/atlas/contracts/2026-Q4.

## 4. Приёмка и ограничения публикации

Для каждой заявки сохраняются время обращения, описание симптома, принятые меры,
результат проверки и подтверждение заказчика. Внешним поставщикам можно передавать
обезличенные коды ошибок, названия открытых стандартов и сведения о версиях ПО.
Передача закрытых ставок, внутренних адресов и персональных контактов без согласования
не допускается. Использование публичных слов HTTP, JSON, Python и PostgreSQL
в описании неисправности само по себе не раскрывает сведения о Заказчике.

Проверка документа должна различать имя компании, название проекта, технический
идентификатор реестра и обычный текст об обязанностях сторон. В данном приложении
нет ни действующего пароля, ни токена доступа: искать секрет по одному слову
«пароль» без значения неправильно.
