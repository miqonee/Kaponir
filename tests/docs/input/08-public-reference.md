# Публичная справка по клиентскому API

Этот документ разрешено публиковать полностью. Он описывает общеизвестные форматы,
открытые стандарты и демонстрационные заглушки. Закрытых проектов, клиентов,
персональных контактов, денежных условий и действующих данных доступа здесь нет.

## Форматы и коды ответа

Клиент может отправлять JSON по HTTP/1.1 или HTTP/2. Для шифрования транспорта
используется TLSv1.3. Ответ 200 означает успешное выполнение, 400 — ошибку параметров,
401 — необходимость авторизации, 404 — отсутствие ресурса, 429 — превышение частоты,
502 — ошибку промежуточного сервера. Числа 200, 400, 401, 404, 429 и 502 в этой
таблице не являются ценами, портами или номерами закрытых договоров.

Публичная документация Python: https://docs.python.org/3/.
Публичная документация PostgreSQL: https://www.postgresql.org/docs/.
Реестр RFC: https://www.rfc-editor.org/.
Зарезервированные примеры адресов: example.com и example.org.

## Пример структуры запроса

```json
{
  "model": "gemini-3.8-flash",
  "stage": "s1",
  "questions": ["What is JSON?"],
  "character": "|",
  "temperature": 0,
  "stream": true,
  "timeout_seconds": 30
}
```

Слова character и questions являются именами полей. Строка s1 — обозначение этапа
в опубликованном примере, а не имя частного домена. gemini-3.8-flash — публичное
название модели. Названия OpenAI, Python, Docker, Linux, Redis и PostgreSQL также
не требуют скрытия только потому, что встречаются в техническом тексте.

## Заглушки и фрагменты кода

В примерах форм используются password=***, token=<redacted> и existing=ANON_SECRET_19.
Многоточие ... показывает, что часть примера опущена. Перечисленные строки не дают
доступа ни к одной системе. В коде могут встречаться куски e::, ::C и ::f: это
не полные сетевые адреса, и выделять их как IP-адреса в этом примере неправильно.

## Версии и размеры

Для примера можно указать Python 3.13, PostgreSQL 17, Redis 7 и Docker Compose v2.
Значения 1024 байта, 16 МБ и 2 секунды — размеры и интервалы, а не коммерческие суммы.
Фразы «если значение пустое» или «оставить поле открытым» не обозначают проект.
При проверке этого текста не должно появиться ни одного нового чувствительного значения.
