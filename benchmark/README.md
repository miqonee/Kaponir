# Benchmark: отчёт и точка продолжения

Архив завершённого исследования Kaponir за 11–14 ноября 2026 года, собран 15 ноября.
База исходного кода и итоговых результатов: `627f58d`.
Все семь моделей прошли шесть основных схем; обе очереди завершены. Новые гипотезы
следующего этапа ещё не проверялись. Упаковка не запускала моделей.

**Вывод:** LLM полезна для дополнения поиска. Автоматическое отклонение приватных
находок пока ненадёжно; следующий фокус — явная политика анонимизации и более простой
контракт проверки, затем проверка на свежих документах.

## Что сохранено

- 41 опубликованная контрольная точка, полный JSON-свод и исходный корпус с разметкой.
- Дополнительные ранние, неудачные и прерванные опыты, внешние прогоны и проверка UI.
- Доступные журналы, карточки моделей, служебные скрипты и диагностики сессии.
- Снимки интерфейса; одинаковые данные связаны ссылками в каталоге вместо дублирования.
- Полная достижимая Git-история исходной базы в offline bundle — 36 коммитов.
- SHA-256, происхождение, статусы и явный список исключённых операционных файлов.

Веса GGUF, vault/БД, рабочие ключи и кеши инструментов не нужны для чтения результатов.
Параметры моделей, закреплённые ссылки и SHA сохранены. Подробности исключений —
в [карте доказательств](EVIDENCE.md); это не копия пользовательского Vault.

## Быстрая проверка

Из корня репозитория, только Python 3.10+:

```sh
python3 benchmark/verify.py
```

Проверка читает только пакет, сверяет все файлы и архивы, пересчитывает 42 ячейки
основной матрицы. Она не требует модели, сети, Cargo или доступа к исходным `/tmp`.
Папку можно перенести: `python3 /новый/путь/benchmark/verify.py`.

Содержимое снимка зафиксировано [manifest.json](manifest.json). Для нового этапа
создавайте новый каталог результатов; старые числа и контрольные точки остаются
доступной базой сравнения.
