# Рейтинг одной модели, настройка профилей и проверка типов

20 ноября 2026 года. В дополнение к исследованию 15 моделей пересчитаны баллы для одного работающего экземпляра модели, проведены 16 коротких запросов к пяти моделям и отдельный тест Liquid d1-3B на 12 значениях. Использованы уже размеченные синтетические документы. [Основное исследование](ALL_MODELS.md)

В CSV также есть полное время попытки, процессорное время, пиковая память, размеры входа, пропуски и ошибки. [Все 16 измерений](focused-tuning.csv)

Для точного повторения компактного Qwen в варианте D использованы контекст 4096, лимит ответа 900, `enable_thinking=true`, бюджет рассуждений 256, температура 1, top-p 0,95, top-k 64, min-p 0, seed 42 и JSON Schema. В быстром варианте по карточке Qwen рассуждения выключены, температура 0,7, top-p 0,8, top-k 20, presence penalty 1,5 и repeat penalty 1,0. Сохранён отдельный запуск с выключенными рассуждениями и общими параметрами для сравнения влияния режима.

При применении решений Qwen через API один журнал содержал 113 приватных и 32 публичных вхождения. Одни детекторы полностью скрыли 39 приватных вхождений, оба компактных профиля без рассуждений — 53, с ограниченными рассуждениями — 67. Все 32 публичных сохранились. По 11 конфигурациям проверены 22 пары скрытия и восстановления журнала, включая базовые варианты. Во всех случаях исходный текст восстановился точно, постоянные правила остались прежними. [Применение через API](focused-application.csv)

У Granite две лишние замены в публичной справке основного исследования пришли из исходных предложений детекторов. Собственный список находок модели по этой справке был пуст. В пользовательском сценарии обнаруженные значения можно предлагать на подтверждение.

## Liquid d1-3B и выбор словаря

Один нативный вызов System1 на значение, два вопроса — тип и область словаря. Проверены 12 значений из сметы и журнала, 26 вариантов типа и три области. Модель верно выбрала тип у **10 из 12**, область у **9 из 12**, оба признака у **8 из 12**. Время 12 запросов составило 200,3 с, медиана 15,6 с, пик ОЗУ модели 2,87 ГиБ. В таблице доступны эталон, ответ, уверенность и время по каждому примеру. [12 результатов](d1-categorization.csv)

| Минимальная уверенность | Тип, верно / принято | Область, верно / принято | Оба признака, верно / принято |
|---|---:|---:|---:|
| 85% | 3/3 | 4/4 | 0/0 |
| 64% | 5/5 | 5/5 | 2/2 |
| 36% | 10/12 | 9/12 | 8/12 |

Для совместного принятия оба признака должны пройти порог. При 85% совместных принятий не было. Изменение порога регулирует отправку на ручную проверку. На этом срезе модель путала учётную запись с сервисом, клиента с организацией и области словаря для суммы и пользовательского типа.

Нативный интерфейс модели принял все 12 запросов. Интеграционный тест Kaponir получил HTTP 400. Диагностический запрос воспроизвёл несовместимость формата вопроса Choice — адаптер передавал массив `choices`, а этот runtime ожидает объект `criteria`. Постоянных правил тест не создавал.

## Как рассчитан балл при одном работающем экземпляре

В таблице каждой из 15 моделей соответствует одна строка. Отдельно приведены лучшая измеренная схема поиска и лучший вариант A–D. Пустое поле означает отсутствие измеренного результата для рейтинга. У 13 моделей доступны схемы поиска, у 14 — оцениваемые ответы A–D. Для строгого сравнения поиска по одинаковому запрошенному профилю следует брать группы `archived_shared_requested` и `new_matched_reference`, вместе девять моделей. [Рейтинг с исходными показателями](single-model-ranking.csv)

Для **поиска** использована формула `50 × H/193 + 15 × (1 − L/87) + 5/(1 + R) + 30 × T/(T + t)`. Здесь H — полностью скрытые приватные вхождения, L — потерянные публичные контроли, R — число замен в полностью публичной справке, t — время запросов схемы в минутах. Опорное T равно 11,5491379607 минуты, медиане добавляющего поиска. В сопоставимой группе при весе времени 30 из 100 наибольший балл у Gemma 4 E4B QAT с добавляющим поиском — 73,59. Если обязательна сохранность всех 87 публичных контролей, у Granite с добавляющим поиском 145 полностью скрытых вхождений и две замены вне контролей. Если нужна также неизменная публичная справка, у Nanbeige с перепоиском 131 скрытое вхождение.

Для **A–D** формула равна `50 × M/16 + 20 × K/16 + 30 × T/(T + t)`. M — верные решения скрыть приватное, K — верные решения оставить публичное. Все 32 цели входят в знаменатели, включая цели без ответа. Опорное T равно 51,77481835 минуты, медиане вариантов с известной длительностью и полученными решениями. У Gemma 4 E4B QAT вариант D набрал 76,55 балла — 14 верных приватных MASK, 15 верных публичных KEEP и 58,80 минуты. Неполные сведения о времени архивных вариантов учтены как нижние границы и проверены при выборе лучшего варианта. Память приводится для подбора оборудования.

Для пересчёта рейтинга опубликованы длительности с полной точностью и показатели качества всех 65 сочетаний поиска и 60 сочетаний A–D. [Входные показатели рейтинга](single-model-scoring.json)
