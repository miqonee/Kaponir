# Переносимый снимок новых измерений

Снимок сохраняет завершённые синтетические прогоны отдельно от неизменяемого
[прежнего benchmark](../../benchmark/README.md). Исходные JSON-байты сжимаются с
фиксированным gzip mtime; запросы, полные ответы, неприменимые решения и тайм-ауты
не переписываются. Для фактически использованных producer сохраняются исходники
и входы; их SHA проверяются по измерительному плану.

```sh
python3 scripts/export_privacy_snapshot.py \
  --output artifacts/privacy-policy-phase2/exports/checkpoint-unique-name
python3 scripts/export_privacy_snapshot.py \
  --verify artifacts/privacy-policy-phase2/exports/checkpoint-unique-name --rescore
```

Вторая команда проверяет состав, архивные и исходные SHA, связи исходной попытки
с дополнением транспорта или политикой v2, затем пересчитывает качество без
запуска модели. Её нужно выполнять из соответствующего checkout Kaponir с
замороженными эталонами. Хеши подтверждают целостность связанных локальных
записей, а не независимую аттестацию физического выполнения модели.

Веса, Vault, ключи, загрузочные логи и произвольные каталоги не включаются.
Существующий снимок не перезаписывается. Незавершённые прогоны показываются
ожидающими. Ошибка нативного бюджета либо завершённый технический сбой сохраняются
как диагностика без оценки качества. Отсутствие подходящих тайм-аутов для
дополнения отмечается как N/A, не как отсутствующий ответ.

После регистрации двух Gemma-it состав включает 76 измерительных заданий и
до семи дополнений транспорта: 83 потенциальные записи. Ожидающие задания входят
в manifest со своим состоянием, без выдуманных ответов. Прежние снимки сохраняют
свой первоначальный состав; расширение не меняет их байты.

16 ноября 2026 года первый снимок трёх завершённых серий Gemma/Qwen успешно
перенесён во временный каталог и пересчитан: три прогона, десять архивных файлов,
ноль новых обращений к моделям. Локальный путь:
`artifacts/privacy-policy-phase2/exports/2026-11-16-0030/`.
