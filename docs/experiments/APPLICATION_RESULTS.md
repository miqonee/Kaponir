# Фактическое применение сохранённых схем

16 ноября 2026 года. Проверены семь прежних моделей × шесть схем:
42 результата, 252 точных прохода mask→restore. Использованы сохранённые
[архивные ответы](../../benchmark/data/validation/manifest.json); новых запросов
к моделям не было. Это проверка применения, а не новая генерация или свежая выборка.

## Что именно проверено

[Скрипт применения схем](../../scripts/apply_scheme_masks.py) сначала проверяет
артефакт, исходные документы и пересчитанные метрики архивного результата. Затем
пригодные MASK и защищённые кандидаты детекторов передаются настоящему API приложения.
Для каждого документа и прохода создаётся отдельный временный home с S1 off.
KEEP не создаёт исключений, постоянные правила не меняются, временный Vault удаляется.

Все выбранные значения считаются явно подтверждёнными для этого документа.
Применяется CUSTOM/personal: тип и контур, предсказанные моделью, не переносятся.
Поэтому таблицы не доказывают пригодность исходных типов и не разрешают автоматическое
применение рекомендаций. Разметка используется только для оценки результата, не для выбора MASK.

Корпус — прежние смета, лог и полностью публичный контрольный документ:
92 размеченных приватных значения, 193 их вхождения и 87 вхождений публичных контролей.
Приватные диапазоны могут пересекаться; это не 193 независимых события.
Публичные контроли не исчерпывают все открытые слова документа.

Таблицы ниже относятся к сохранённому бинарнику до последующего
[исправления коллизий технических слов](PRODUCT_FINDINGS.md).
Его SHA: `7f1ad022b278876fc875571edbbeac8ffc91cd30edf9c672be5f11451fcce2b3`.
Отдельное сравнение через API убрало пять ложных замен технических слов,
сохранив размеченное приватное покрытие и публичные контроли. Архивные ответы,
входы и результаты этих 42 применений задним числом не пересчитываются.

## Как читать покрытие

- **Полностью**: замены перекрыли весь исходный размеченный диапазон.
- **Частично**: замены перекрыли только часть диапазона.
- **Не затронуто**: ни одна замена его не перекрыла.
- **Потеряно контролей**: сколько из 87 открытых контрольных вхождений исчезло.
- **Замен в публичном документе**: все фактические замены в полностью публичном тексте,
  включая слова вне списка контролей.

Покрытие считается по UTF-8-координатам исходного текста. Подстановка каждого токена
по этим координатам должна точно воспроизвести полученный маскированный текст;
это учитывает склонения имён, где API может хранить лемму вместо буквальной подстроки.
Проверяется и полное обратное восстановление.

Геометрическое покрытие не является доказательством отсутствия остаточной информации.
У частично заменённого значения оставшиеся символы могут быть как чувствительными,
так и общими. Отсутствие целого исходного значения в результате само по себе
не доказывает полного скрытия всех его чувствительных частей.

## Что следует из проверки

Добавляющий поиск даёт существенно большее покрытие, но может скрывать публичные
сведения. У архивной Gemma объединение поиска с предложениями детекторов полностью
перекрыло 173 диапазона и частично 20, потеряв 10 контрольных вхождений и сделав
семь замен в полностью публичном документе. Нулевое число нетронутых диапазонов
здесь не означает безошибочную защиту.

Проверка списка и дополнительный проход часто отбрасывают полезные предложения:
у нескольких моделей фактическое покрытие после них совпало с обычными детекторами.
Защищённые детекторные MASK считаются отдельно от правильных решений модели.
Неизменённый публичный контроль не доказывает отсутствия остальных ошибок или пропусков.

В новой серии Gemma D/v1 после применения решений для 32 готовых целей получено
83 полностью перекрытых диапазона, 6 частично перекрытых и 104 нетронутых;
87 открытых контрольных вхождений сохранены. Это другая постановка и профиль,
поэтому разницу с архивной таблицей нельзя приписывать одному изменению prompt.
Применимость короткого решения не заменяет полноту поиска.

## Воспроизведение и файлы

```sh
python3 scripts/apply_scheme_masks.py \
  --result benchmark/data/validation/gemma-calibration--result.json.gz \
  --archived --method current_union \
  --binary artifacts/product-regression/target/debug/kaponir \
  --output artifacts/product-regression/application-gemma-union
```

Каталог результата должен быть новым. Для новых измеренных схем `--archived`
не нужен; скрипт требует завершённый результат с подтверждённой очисткой runtime.

Локальный сводный файл —
`artifacts/product-regression/apply-previous-seven-v1/summary.json`.
В нём SHA каждого отчёта, ссылка на исходный результат, настройки и итог 252/252.
Индивидуальные отчёты связывают SHA исходных ответов, бинарника и кода применения,
сохраняют настоящие mask/restore-ответы и отсутствие изменений правил.
Предыдущие результаты и неуспешные диагностические проходы не перезаписывались.

Тесты покрытия включают UTF-8, частичную замену, склонение, пересечение диапазонов,
сохранение защищённых кандидатов при ошибке модели и запрет перезаписи доказательств.
Полный Python-набор: 273 теста, один допустимый пропуск в чистом `python3 -S`.
Сравнение всех моделей и свежих документов продолжает общую матрицу;
итоговый default пока не выбран.
