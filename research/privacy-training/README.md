# Пилот дообучения Kaponir

Ветка `research/privacy-training` хранит экспериментальные данные, план и итоговые отчёты по маскированию точных значений. Базовая ревизия Kaponir `d0424adff53bfff18964cf61f7f5e9d2b905b421` содержит опубликованные результаты сравнения локальных моделей.

## Данные v0

| Часть | Фрагменты | Шаблоны и группы источников | Назначение |
|---|---:|---:|---|
| [Train](data/v0/train.jsonl) | 436 | 52 | Обучение. Из них 76 ранее размеченных примеров |
| [Validation](data/v0/validation.jsonl) | 120 | 10 | Выбор параметров и проверка во время обучения |
| [Test](data/v0/test.jsonl) | 132 | 11 | Парная проверка исходной модели и адаптера |

Все фрагменты синтетические. В разметке есть Linux `/home`, доменные логины и UPN, Windows-профили, SSH, SMB, Kubernetes, журналы, конфиги, адреса, токены, внутренние идентификаторы и суммы. Публичные заглушки и неоднозначные значения размечены явно. В одном из фрагментов одинаковая цена из публичного каталога и закрытого договора получает две разные метки по позициям.

Оригиналы 76 ручных примеров сохранены в [разметке значений](data/seeds/annotation-seed.jsonl) и [сценариях раскрытия](data/seeds/access-classification-seed.jsonl). Остальные фрагменты воспроизводятся из [синтетических шаблонов](synthetic_cases.py). [Манифест](data/v0/manifest.json) фиксирует SHA-256, состав частей и число меток. `validation` и `test` содержат отдельные шаблоны. Варианты одного шаблона остаются в одной части.

## Расширение v1

В новых случаях есть фрагменты с пустым ответом, IPv4 с префиксом, IPv6 с портом и зоной, закрытые имена модулей, вложенный JSON, неодинаковые пробелы в суммах и значения, которые входят в другие строки как префикс. ## Проверка переноса в v2

В v1 нашёлся позиционный признак. Во всех фрагментах, где одна строка размечена и как публичная, и как приватная, публичное вхождение стояло первым. Таких фрагментов было 27 в обучении, 12 в валидации и 12 в тесте. В v2 каждый из них получил вариант с обратным порядком предложений или строк CSV. Сведения о происхождении перемещаются вместе со значением. Обе версии входят в одну часть данных.

Ещё 21 фрагмент образует девять отдельных серий. В каждой части данных есть по одной серии каждого из следующих видов.

| Что меняется | Что должна сделать модель |
|---|---|
| Происхождение значения | Для одной строки выдать `keep` в подтверждённом вымышленном примере, `mask` в рабочей записи и `review` при неизвестном происхождении |
| Роль значения | Присвоить разные типы одному и тому же имени, сохранив решение о маскировании |
| Формат документа | Восстановить прежнее решение и точное значение после переноса записи в другой формат |

Например, в учебной серии путь `/home/ivar.len/cache/index` записан одинаково трижды. Меняется только подпись об источнике. В одном случае учебник использует вымышленную учётную запись, в другом инженер приводит пример со служебного ноутбука, в третьем происхождение пути выяснить не удалось. Во всех случаях тип `ivar.len` остаётся `USER`. [Исходная разметка v2](data/extensions/v2.jsonl)

| Часть | Всего фрагментов | Пар с обратным порядком | Дополнительных серий |
|---|---:|---:|---:|
| [Train](data/v2/train.jsonl) | 496 | 27 | 3 |
| [Validation](data/v2/validation.jsonl) | 149 | 12 | 3 |
| [Test](data/v2/test.jsonl) | 163 | 12 | 3 |

Серия засчитывается целиком, когда во всех её фрагментах верны значения, типы, действия и номера вхождений. В тесте 12 пар порядка принадлежат одному шаблону. Остальные три серии используют новые группы источников, в том числе запись в формате `.netrc`, которого нет в обучении. [Манифест v2](data/v2/manifest.json)

## Пример разметки

Этот фрагмент `annotation-seed/seed-003` входит в данные начиная с v0.

```text
Public catalog price for the standard package: USD 1,870.00.
Confidential negotiated amount for a separate support agreement: USD 1,870.00.
```

В эталонном ответе решение размечено отдельно для каждого вхождения.

```json
{"spans":[
  {"value":"USD 1,870.00","kind":"AMOUNT","action":"keep","occurrence":1},
  {"value":"USD 1,870.00","kind":"AMOUNT","action":"mask","occurrence":2}
]}
```

## Проверка и экспорт

Команды выполняются из корня репозитория с Python 3.10 или новее.

```sh
python3 research/privacy-training/dataset.py check --data research/privacy-training/data/v2
python3 research/privacy-training/dataset.py export --data research/privacy-training/data/v2 --output artifacts/privacy-training/sft-v2
```

Проверка сверяет байтовые границы, преобразование каждой метки в точное вхождение, отсутствие пересечений групп между частями и идентичность снимка исходникам. Экспорт создаёт `train.jsonl` и `validation.jsonl` в диалоговом формате `prompt`/`completion` для TRL. `test-inputs.jsonl` содержит только запросы. Связи внутри серий и эталон теста остаются в канонической разметке. Для повторной сборки можно использовать `dataset.py build --version v2`.

[План обучения и проверки](TRAINING_PLAN.md) содержит параметры для RTX 4080 Laptop и критерии сравнения. [Отчёты](reports/README.md) содержат зафиксированную исходную точку и формат хранения итогов.
