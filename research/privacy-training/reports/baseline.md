# Исходные замеры до обучения

Снимок опубликованного исследования из ревизии `d0424adff53bfff18964cf61f7f5e9d2b905b421`. Сводка относится к синтетической смете, журналу приложения и публичной справке. Применение измерялось через API на 193 приватных вхождениях и 87 публичных контрольных вхождениях. [Итог по 15 моделям](https://github.com/miqonee/Kaponir/blob/d0424adff53bfff18964cf61f7f5e9d2b905b421/docs/experiments/ALL_MODELS.md)

Для исходной Qwen доля полного скрытия составила 89,6%. Из 20 неполных скрытий 16 пришлись на журнал приложения. На том же наборе достижение 95% означало бы минимум 184 полных маски, на 11 больше исходного результата. Это арифметический ориентир для исторических документов. [Результаты по документам](https://github.com/miqonee/Kaponir/blob/d0424adff53bfff18964cf61f7f5e9d2b905b421/docs/experiments/new-models-reference-v2-documents.csv)

Протокол фиксировал кандидатов и считал фактическое применение отдельно.
