Фоновое обнаружение

Завершённые ходы и документы. Текущий запрос не ждёт модель.

Анализирует очередь сообщений и документов для накопления правил. Веса модели не изменяются. При выключении очередь сохраняется, действующие правила продолжают работать.

Текст фонового анализа передаётся выбранному API-серверу. Используйте доверенное подключение.

Для OpenAI-совместимого API подойдут адреса /v1, /chat/completions или /models.

Ключ будет удалён после сохранения настроек. Пустое поле без галочки сохраняет прежний ключ.

Один вопрос с вызовами инструментов образует одно задание. Проверка начинается после ответа агента или минуты без новых шагов.

Модель обнаружения проверяет новые находки по мере появления. При включённом автосоздании проверенные значения с решением «скрыть» и оценкой выше порога переходят в «Разобранные».

Находки, прошедшие проверку по исходнику и категоризацию с оценкой строго выше порога, становятся правилами. При выключении все находки требуют подтверждения.

При пороге 85% оценка ровно 85% требует подтверждения. Оценка модели не является измеренной вероятностью правильного решения.

Число одновременно обрабатываемых заданий. Увеличение требует больше CPU и памяти; начните с одного.

Дополнительные параметры

Максимальное ожидание одного обращения к модели. По истечении времени задание можно повторить из журнала.

Общий бюджет входа и ответа на одно обращение. Локально используется токенизатор загруженной модели. Больший контекст требует больше памяти; задайте размер, который поддерживает ваша модель. Для API без токенизатора вход планируется по консервативному пределу UTF-8 байтов.

Место, заранее отведённое под JSON-ответ. Оно вычитается из общего контекста до разбиения текста. При обрыве обнаружение повторяется на меньшем фрагменте.

Дополнительный запас между входом и лимитом ответа. Сумма лимита ответа и резерва должна быть меньше контекста.

Сколько значений проверять за одно обращение. 1 — отдельный запрос для каждой находки. Большему пакету нужны контекст, лимит ответа и время; при обрывах уменьшите пакет.

Режим для обращений к LLM. Авто проверяет поддержку JSON Schema у локальной среды. «JSON по инструкции» передаёт схему в подсказке без ограничителя; ответ всё равно проверяется. Нативный S1 использует собственный протокол.

Режим «Только значения» уменьшает ответ и отделяет поиск от определения типа. Тип определит категоризация; если она выключена, находки останутся без определённого типа до вашего решения.

Автоматический режим объединяет абзацы в пределах бюджета. Режим по абзацам отправляет каждый абзац отдельно. Длинные абзацы делятся по строкам и словам; при обрыве ответа фрагмент делится повторно.

0 — заполнение доступного контекста. Меньшее значение сокращает фрагменты и может помочь небольшой модели сосредоточиться на деталях. Учитываются инструкция и контекст фрагмента.

Бюджет заголовков документа и таблицы, добавляемых к фрагменту. Они помогают понимать значения между частями. 0 отключает дополнительный контекст.

Верхняя граница списка находок в JSON. Если ответ содержит столько разных значений из исходника, фрагмент проверяется частями, чтобы найти пропущенное.

Защитный предел, включая повторы на меньших фрагментах. При достижении лимита полученные находки сохраняются на подтверждение, а задание можно повторить.
