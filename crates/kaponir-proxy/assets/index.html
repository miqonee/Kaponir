Фоновое обнаружение

Завершённые ходы и документы. Текущий запрос не ждёт модель.

Анализирует очередь сообщений и документов для накопления правил. Веса модели не изменяются. При выключении очередь сохраняется, действующие правила продолжают работать.

Текст фонового анализа передаётся выбранному API-серверу. Используйте доверенное подключение.

Ключ будет удалён после сохранения настроек. Пустое поле без галочки сохраняет прежний ключ.

После успешного ответа прокси новые входные сообщения попадают в очередь. При выключении документы можно отправлять вручную. Ответы ассистента используются только как контекст.

Находки, прошедшие проверку по исходнику и категоризацию с оценкой строго выше порога, становятся правилами. При выключении все находки требуют подтверждения.

При пороге 85% оценка ровно 85% требует подтверждения. Оценка модели не является измеренной вероятностью правильного решения.

Число одновременно обрабатываемых заданий. Увеличение требует больше CPU и памяти; начните с одного.
