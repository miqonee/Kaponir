Контекст помогает оценке

L0

Только признаки: форма, длина, тип. Минимум передаваемых данных; смысл окружающего текста недоступен.

L1

Само значение и его признаки. Больше информации о кандидате, но без окружающего текста.

L2

Значение и маскированный фрагмент. Максимум контекста в текущей версии; помогает различать публичное и внутреннее использование.

Распознанные пароли и ключи ограничиваются L0. Оценки S1 дополняют детекторы и правила.

Где запускать S1

Для L2 подойдёт проверенный провайдер или ваш HTTP-сервис — на этой машине либо отдельном сервере. Вычисления модели выполняются там, где она развёрнута.

Локальное размещение — вариант, а не обязательное условие. Для разового разбора документов можно использовать отдельный обработчик, запускаемый по запросу.

Модели и очередь заданий

    

      
Xiaomi-OCR-0
Xiaomi может читать сканы и искать кандидатов в документах. Находки сохраняются в подборку для оценки S1 или вашего подтверждения.
Веса и визуальный модуль скачиваются на машину worker. При необходимости устанавливается CPU runtime для Linux x64. Модель выгружается после задания.

      
Добавить задание
В режиме Xiaomi текст отображается страницами для модели. Нужны загруженная модель и Pillow; обработка занимает больше времени. Значения сверяются с исходным текстом.
S1 оценивает находки по выбранному уровню L0–L2. Правила подтверждаете вы. Завершённую сессию можно подать файлом; живой трафик автоматически не записывается.

    

    
Задания
Пауза и отмена сохраняют уже собранных кандидатов. Отдельный процесс использует общие ресурсы машины; задайте лимиты или разместите worker на другом сервере.

  

  

    

      
Анализ документов и подборка

      
По умолчанию анализ локальный. Оценка S1 и сохранение подборки включаются отдельно; правила создаются только после подтверждения.

      

        
        Файлы читаются браузером локально и отправляются только этому серверу Kaponir при анализе.
      

      
      
      
S1 получит признаки или значения с контекстом согласно настройкам L0/L1/L2. Другие найденные значения в контексте скрываются. Оценка не создаёт правил.

      
      
В подборке сохраняются значения и короткие примеры, а не полные документы. Повторная загрузка того же документа не увеличивает счётчики.
